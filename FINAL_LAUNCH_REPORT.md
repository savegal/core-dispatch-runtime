## 🚀 Порядок запуска

### 1. Установка зависимостей:
```bash
pip install -r requirements.txt
python -m playwright install chromium
```

### 2. Запуск Redis:
```bash
# Windows (если установлен)
redis-server

# Linux
sudo systemctl start redis
```

### 3. Запуск сервисов (4 процесса):

**Терминал 1 — Backend API:**
```bash
uvicorn main:app --reload --port 8000
```
✅ Должен показать: `Uvicorn running on http://127.0.0.1:8000`

**Терминал 2 — Telegram Bot:**
```bash
python -m bot.app
```
✅ Должен показать: `Bot started` и подключиться к Telegram

**Терминал 3 — Executor:**
```bash
python -m executor.executor
```
✅ Должен показать: `Executor started, waiting for tasks...`

**Терминал 4 — Video Monitor (опционально):**
```bash
python -m services.video_monitor_worker
```
